# Assignment 38 :

This folder contains problems related to digits in which input is taken from user as a Integer, problems are:-

1. Accept String from user & copy that characters of that string into another string in reverse order.
2. Accept String from user & copy that characters of that string into another string by removing all white spaces.
3. Accept String from user & copy that characters of that string into another string by converting all small character into capital.
4. Accept String from user & copy that characters of that string into another string by converting all Captil character into Samll.
5. Accept String from user & copy that characters of that string into another string by toggle the case.

Commands used to execute these codes are:-

gcc filename.c -o myexe myexe
