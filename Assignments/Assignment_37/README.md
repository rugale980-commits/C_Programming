# Assignment 37 :

This folder contains problems related to digits in which input is taken from user as a Integer, problems are:-

1. Accept String from user & accept one character and Check presnt or not.
2. Accept String from user & accept one character & Check Frequency.
3. Accept String from user & accept one character return index of First Occurrence of that character.
4. Accept String from user & accept one character return index of last Occurrence of that character.
5. Accept String from user & reverse that string in place.

Commands used to execute these codes are:-

gcc filename.c -o myexe myexe
